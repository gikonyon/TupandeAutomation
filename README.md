# Tupande Automation & AI Platform

An interactive prototype demonstrating AI, field automation, and input credit modeling for **One Acre Fund / Tupande** operations in Kenya.

## Features
- **Tupande Duka Credit Simulator:** Dynamic calculation of seed, fertilizer, and tree seedling bundles with M-Pesa repayment trajectories.
- **AI Agronomic Assistant:** RAG-powered decision support for smallholder crop protection and top-dressing fertilizer timing.
- **Regional Risk Analytics:** Micro-climate monitoring, soil moisture tracking, and satellite vegetation index (NDVI) mapping across Western Kenya counties.

## Stack
- **UI & State:** [Streamlit](https://streamlit.io)
- **Data & Visualizations:** Pandas, NumPy, Plotly Express
- **Deployment:** GitHub + Streamlit Community Cloud
